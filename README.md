## Evidence posture

External scientific and technical sources retain their own authorship and authority. NMG architectural integration does not transfer authorship, institutional authority, scientific validation, software release status, or evidentiary authority between independent records.

Research and architecture records distinguish:

- **SOURCE-ESTABLISHED** — supported by the cited source.
- **NMG ARCHITECTURAL INTEGRATION** — authored system wiring / synthesis.
- **COMPUTATIONAL MODEL** — design or simulation state not yet physically qualified.
- **PHYSICALLY VERIFIED** — reserved for evidence that has passed the defined measurement and validation gate.
